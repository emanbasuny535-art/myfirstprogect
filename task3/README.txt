SPICE HAVEN - ASSIGNMENT TWO

Project files:
1. index.html  - Website structure and content.
2. style.css   - Colors, layout, typography and responsive design.
3. script.js   - Mobile navigation and reservation form validation.

How to run:
1. Extract the ZIP file.
2. Open the Spice_Haven_Project folder.
3. Double-click index.html, or open the folder in Visual Studio Code.
4. For VS Code, you can use the Live Server extension and choose "Open with Live Server".

Notes:
- The food images are loaded from Unsplash, so an internet connection is needed to display them.
- Menu names, prices, restaurant address and contact details are sample assignment content.
- The reservation form shows a confirmation in the browser. It does not send/store a real booking because no backend/database is connected.
